# Boosting Algorithm Demo

An interactive teaching site that shows how boosting turns several weak learners into a stronger ensemble. The demo computes three AdaBoost rounds over a small two-class dataset, then visualizes point weights, weighted mistakes, learner confidence, and the ensemble vote.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Phone access

Phone users do not need npm. After GitHub Pages deploys, open:

